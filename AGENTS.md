# Agent instructions

This is a public repository. Anything posted here is published: commit messages, PR titles and bodies, PR and review comments, issue text, code comments, docs, test and fixture names, and log strings. GitHub keeps earlier versions of edited text, so get the wording right before posting.

- Don't name internal Silimate products, customers, private repos, or internal tickets, and don't link to them. Describe changes in upstream terms, and back results with this repo's own tests.
- Check the repo's visibility before posting; treat anything you can't confirm as public.
- If you can't tell whether a name is public, ask before posting.
